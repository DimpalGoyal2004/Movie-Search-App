# Movie-Search-App
A responsive movie search application built with HTML, CSS and JavaScript using the OMDb API, Fetch API, async/await, filters and pagination.
<br>

Features
🔎 Search movies by title
🎬 Display multiple movie results
🖼️ Display movie posters
📅 Filter movies by year
🎞️ Filter results by movie or series
⬅️ Previous and Next pagination
📄 Display current page and total pages
⏳ Loading state while searching
❌ Error and no-result handling
⌨️ Search using the Enter key
📱 Responsive design for different screen sizes
🌙 Modern dark/glassmorphism UI
🛠️ Technologies Used
HTML5
CSS3
JavaScript (ES6+)
Fetch API
Async/Await
DOM Manipulation
OMDb API
🌐 API

This project uses the OMDb API to retrieve movie information.

The API provides information such as:

Movie title
Release year
Movie type
Poster
Total search results
🔄 How It Works

The application follows this flow:

User enters movie name
        ↓
JavaScript creates API URL
        ↓
Fetch API sends request
        ↓
OMDb API returns JSON data
        ↓
JavaScript processes the data
        ↓
Movie cards are created dynamically
        ↓
Results are displayed on the page
